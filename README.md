👻 GHOSTSCOUT V3.0
ADVANCED CYBER TERMINAL — KALI LINUX EDITION

GHOSTSCOUT adalah aplikasi terminal bertema cybersecurity
yang dibuat menggunakan Python untuk Kali Linux.

Aplikasi ini menghadirkan tampilan terminal bergaya hacker
dengan warna Matrix hijau, animasi boot, menu CLI interaktif,
dan dashboard lokal berbasis browser.

---

## ✨ FEATURES

- Hacker-style terminal interface
- Matrix rain animation
- Animated boot sequence
- Interactive CLI menu
- Local system information
- Local network interface overview
- Futuristic browser dashboard
- Animated decorative radar
- Activity feed
- Kali Linux compatible
- Python standard library only

---

## 🖥️ REQUIREMENTS

- Kali Linux
- Python 3
- Terminal emulator
- Web browser

Tidak memerlukan instalasi library Python tambahan.

---

## 📥 INSTALLATION

Update package:

    sudo apt update

Pastikan Python 3 tersedia:

    python3 --version

Buat file:

    nano GHOSTSCOUT.py

Tempel kode utama GHOSTSCOUT V3.0,
kemudian simpan file.

---

## 🚀 HOW TO RUN

Jalankan aplikasi:

    python3 GHOSTSCOUT.py

Jika ingin menjalankan sebagai executable:

    chmod +x GHOSTSCOUT.py

    ./GHOSTSCOUT.py
